Blind replication kit: zebrafish liver single-cell test

Can an AI agent do a bioinformatician's job? We give an agent public single-cell data from a zebrafish liver study, plus the experiment design, but not the paper. Separate agents then check whether it found what the authors found. No step needs biology knowledge from you: terms like UMI and Drop-seq are for the agents.

What counts as success

Pass bar3 of 6 core findings, no major false claims (both defined in the answer key)
Visual proofAgent's figure beside the paper's, plus a scorecard grid
Your roleRun the agents in order. Prasanna judges the biology.

What you're getting

Run from the public GitHub repo, blind-replication-kit-public; start with README.md, it has every command. Only the answer key and scorecard template are kept out of it. They live in the private repo and are needed only for grading.

Run order

  1. Setup, with internet. bash not-for-analyst/setup_data.sh ~/blindtest/analyst downloads the data, blinds it, and copies in the brief, sample sheet and environment list. Use a work folder outside the repo.
  2. Build the sandbox. Install everything in environment.md while online, then cut the network and mount only the analyst folder.
  3. Analyst, Part 1. Fresh agent. Prompt: "Read analysis-brief.md and follow it. Save all outputs under outputs/." Then freeze a copy of Part 1 with checksums.
  4. Analyst, Parts 2 and 3. Add followup-questions.md. Prompt: "Read followup-questions.md and follow it." Keep the transcript.
  5. Two graders, separate fresh sessions, no internet. Each gets the grader instructions, the answer key and a blank scorecard from the private repo, and the analyst's outputs under a neutral name.
  6. Reconciler merges the gradings into one scorecard and a short list for Prasanna.
  7. Prasanna decides the open points.
  8. Visuals agent, with internet, makes the side-by-side figure and the scorecard grid.

A runner agent can read the repo and drive these steps, but must never do the analysis itself; it starts a fresh analyst. Log the tool, model, time and cost of every run; nobody knows those numbers yet. Optional: repeat steps 3 to 8 with existing tools such as Biomni or Edison Analysis, and check each tool's terms before publishing a comparison.

Run B, after Run A: the same test from the 91 GB of raw reads, so the agent also has to turn reads into counts. setup_raw.sh downloads and blinds them; the README has the steps.

Never

  • Let the analyst see not-for-analyst/, this page, the setup report, the internet, or the archive.
  • Let the analyst run the download. The archive page names the paper, which would unblind the test.
  • Give the analyst followup-questions.md before Part 1 is frozen.
  • Fine-tune or train a model on this repo.
  • Commit the data. Put the answer key, or grader, reconciler or visuals outputs, in the public repo or its public Actions logs, or make the private repo public. A public answer key can leak into future models.
  • Add lab data that isn't public. Prasanna checks with the institution first.
