AI bioinformatician: what we are trying to do

Turning biological data into conclusions needs a bioinformatician, who can both write the analysis code and judge what the results mean. They are scarce, so experiments wait. We want to know whether an AI agent can do that job well enough for a lab to trust it and plan its next experiments.

Biology in five minutes

Cells, genes and RNA

Every cell in a fish has the same 26,000 or so genes, like the same codebase with different parts active. An active gene is copied into RNA messages, so counting a cell's messages tells you what the cell is and what it is doing.

Single-cell RNA sequencing

What the analyst does with the table

Running the tools is routine. The hard part is judgment: technical noise, such as samples processed on different days, can pass for a discovery. That is what we test.

The animal: zebrafish liver regeneration

The zebrafish liver can regrow after serious damage. In the fish in this study, the main liver cells carry an engineered enzyme that turns a drug into a poison, so the drug kills only those cells. The liver is then sampled on set days as it recovers.

The test

We test the agent where the answers are known: a published study from this field, used like a test set with a reviewed answer key.

Pass bar: at least 3 of 6 core findings fully recovered, with no major false claims. Run A starts from the count table. Run B starts from the raw reads, so the agent also has to build the table.

One limit

The paper is public, so a model may have read it in training. Blinding stops look-ups, not memory. Requiring evidence for every claim makes remembered answers easier to spot, but the clean test comes later, on unpublished data, after Prasanna checks with the institution.

Why it matters

If it works, labs can plan experiments sooner. In the closest public test (scBench-Long, LatchBio, 2026) the best agent passed about 1 run in 4. We found no test on zebrafish, on regeneration, or scored against lab-confirmed findings, though our search was not exhaustive. Details: background/landscape.md.

Words you will see in the kit

Hepatocyte
The main working cell of the liver.
Biliary epithelial cell (BEC)
A cell lining the bile ducts, the liver's drainage tubes.
dpa
Days post ablation: days since the drug treatment that killed the main liver cells.
FASTQ
The raw text files of sequencer reads.
Drop-seq
The droplet-and-bead method used to make this dataset.
GEO
The public NCBI archive where the data are stored.
UMI
Unique molecular identifier: a short random tag on each captured RNA message, so copies made for sequencing count once.
