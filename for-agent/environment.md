# Analysis environment

The sandbox has no internet. Everything below was installed or saved before the network was turned off. If something you need is missing, say so in your report rather than working around it silently.

## Python 3.11

scanpy, anndata, numpy, pandas, scipy, scikit-learn, statsmodels, matplotlib, seaborn, leidenalg, python-igraph, harmonypy, scrublet, pydeseq2, gseapy, decoupler, liana, jupyter

## R (optional)

Seurat, edgeR, limma, clusterProfiler, org.Dr.eg.db, msigdbr (with its data package)

## Reference files in `resources/`

- Zebrafish gene annotation: Gene Ontology annotations for zebrafish genes.
- Zebrafish to human ortholog table.
- Human gene sets: MSigDB Hallmark and GO, as .gmt files.
- Pathway and transcription factor resources for decoupler (PROGENy, CollecTRI), saved locally.
- A ligand-receptor resource (for example the liana consensus resource), saved locally.

Check the `resources/` folder for the exact file names and versions.
