# Eski run instructions

Updated Oct 8, 2026.

The current steps for the Eski run are in the private repo, `prasvramachandran/blind-replication-kit`, on the `eski-kit` branch. Follow that version. The older steps that used to be here are retired, so do not run the Eski steps from this repo.

What stays in this public repo:
- `for-agent/eski/`: the analysis brief, the follow-up questions and the sample sheet.
- `not-for-analyst/setup_eski.py`: the script that downloads the public data and builds the blinded analyst folder.

The analyst must never see `not-for-analyst/`.
